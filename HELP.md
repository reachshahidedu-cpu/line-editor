# Simple Line Editor - Help

## Commands

### insert

Inserts a new line of text at the specified line number.

Usage:
Enter `insert`, then enter the line number and the text.

Example:
insert
1
Hello World

### delete

Deletes the line at the specified line number.

Usage:
Enter `delete`, then enter the line number.

Example:
delete
1

### display

Displays all current lines with their line numbers.

Usage:
Enter `display`.

Example output:
1: Hello World
2: Welcome to Activity 7

### quit

Exits the line editor.

Usage:
Enter `quit`.

Example output:
Exiting editor.
