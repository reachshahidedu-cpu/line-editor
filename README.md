# Simple Line Editor in C

## Team Member

- Mohammed Shahid Hussain

## Features Implemented

1. Insert a line
2. Delete a line
3. Display the document

## Data Structure

The editor uses an array of strings to store document lines in memory.

## How to Compile

gcc line_editor.c -o line_editor

## How to Run

./line_editor

## Commands

- insert - Insert a new line at a specified line number.
- delete - Delete a line using its line number.
- display - Display all current lines with their line numbers.
- quit - Exit the editor.
